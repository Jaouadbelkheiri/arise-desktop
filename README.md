# ARISE for Windows

[Download the latest Windows installer](https://github.com/Jaouadbelkheiri/arise-desktop/releases/latest)

ARISE is a standalone Windows app with its own runtime, integrated League connection, native monitor companions and in-app DPM rune handoff. Chrome and a separate Node.js installation are not required.

Install the `.exe` from Releases. If the old connector is running, ARISE asks before replacing its connection and sign-in shortcut. Press **Alt** for the ARISE menu, including Windows startup, refresh and update controls.

The live interface updates when ARISE refreshes. Desktop releases download in the background and require an **Update and restart** confirmation outside an active match.

The first release is unsigned, so Windows may display an unknown-publisher warning. Browser-local saved corrections are not automatically migrated from the Chrome app. Third-party sites retain their own access and freshness rules. Rune imports require an explicit click in ARISE.

This repository contains installers and update metadata. Application development is maintained separately.
